# Solicita Comunidade

Protótipo acadêmico para o Projeto Integrador de Tecnologia da Informação II – UFMS Digital.

## Tecnologias
HTML5, CSS3, JavaScript e Vue.js 3 via CDN.

## Funcionalidades
Registro de solicitação, geração de protocolo, consulta e validação básica.

## Execução
Abra `index.html` em um navegador com internet para carregar o Vue.js pela CDN.

## Limitações
Não é canal oficial e não utiliza dados pessoais reais.
